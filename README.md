# Папки суду ⚖️ — «Справи-блискавки»

Міні-гра для уроку 3 «Суд щоденних справ» (LetMe/teens, модуль «Сміливий голос», 9–10 років).

- **Екран гри** — `index.html`: його тренер демонструє дітям у Zoom / Google Meet.
- **Пульт тренера** — `pult.html`: в іншій вкладці / вікні (не демонструвати).

Чистий HTML + CSS + JS, без збирання. Мережа потрібна лише для Google Fonts (і Firebase, якщо ввімкнено).

## Як провести

1. Відкрийте екран гри, натисніть `F` (повний екран) і почніть демонстрацію **саме цієї вкладки/вікна**.
2. Відкрийте пульт: кнопка «🔗 Пульт» у правому нижньому куті екрана гри (або просто `pult.html` у сусідній вкладці того самого браузера). Зелена крапка = підключено.
3. На пульті оберіть папку → тренер читає прохання в ролі персонажа → дитина відповідає голосом →
   бейджі (`🛑` `💬` `⭐`) → «➡️ Перепитати» → «✅ Вердикт» → «← До столу».
4. «🏁 Завершити засідання» — підсумковий екран. «Новий урок» — скинути закриті справи.

Звук печатки й шурхоту вмикається на пульті (за замовчуванням вимкнено). Якщо звуку не чути — клацніть один раз по екрану гри (браузер вимагає дії користувача).

### Клавіші на екрані гри (якщо пульт не відкрився)

| Клавіша | Дія |
|---|---|
| `F` | повний екран |
| `Space` | наступний крок |
| `Esc` | до столу |
| `1` `2` `3` | бейджі |
| `P` | перепитати |
| `S` | ще спроба |
| `V` | вердикт |

Також можна клацнути по папці на столі.

## Пульт на телефоні (необов'язково)

`BroadcastChannel` працює лише між вкладками одного браузера. Щоб керувати з телефона:

1. Створіть проєкт Firebase → Realtime Database.
2. Вставте адресу бази у `config.js` → `firebaseDatabaseURL`.
3. Правила бази (публічний доступ лише до `rooms/{код}`, кімнати живуть 24 години):

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "rooms": {
      "$code": {
        ".read": "$code.matches(/^[0-9]{4}$/)",
        ".write": "$code.matches(/^[0-9]{4}$/) && (!data.child('meta/createdAt').exists() || data.child('meta/createdAt').val() > now - 86400000 || !newData.exists() || newData.child('meta/createdAt').val() == now)"
      }
    }
  }
}
```

Екран гри показує 4-значний код біля «🔗 Пульт»; на телефоні відкрийте `pult.html?room=КОД` або введіть код у пульті.
Без Firebase усе працює в одному браузері, а екран підказує «Відкрийте пульт у сусідній вкладці».

## Файли

- `index.html`, `style.css`, `game.js` — екран гри (єдине джерело стану, прогрес у `localStorage`);
- `pult.html`, `pult.css`, `pult.js` — пульт;
- `data.js` — 10 справ (спільні для обох сторінок);
- `sync.js` — зв'язок (BroadcastChannel + необов'язковий Firebase REST);
- `config.js` — налаштування Firebase.
